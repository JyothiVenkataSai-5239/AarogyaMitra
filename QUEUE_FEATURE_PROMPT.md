# Patient Features

1. Patient Registration
   - Patient can create a new account.

2. Patient Login
   - Patient can log in using email and password.

3. View Hospitals
   - Patient can see the available hospitals.

4. Book Appointment
   - Patient can book an appointment with a hospital.

5. Enter Health Details
   - Patient can enter disease, age, visit type, and emergency details.

6. Doctor Type Selection
   - System selects or suggests the doctor type based on the disease.

7. Emergency Priority
   - Emergency patients get higher priority in the queue.

8. Senior Citizen Priority
   - Senior patients get priority based on age.

9. View My Appointments
   - Patient can see all booked appointments.

10. Live Queue Status
    - Patient can see queue number and current waiting status.

11. Estimated Waiting Time
    - Patient can see the expected waiting time before their turn.

12. Patient Check-In
    - Patient can check in for the appointment.

13. Real-Time Queue Updates
    - Patient queue details update live when admin changes the queue.

## Simple Explanation

This project helps patients register, log in, book hospital appointments, get doctor type suggestions based on disease, and track their live queue number and waiting time in real time.
